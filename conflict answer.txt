Explanation of conflicts and how to resolve them:
A conflict occurs when two branches originate from the same commit and modify the same line in `config.txt` to different values. Consequently, during a merge, Git cannot determine which version to keep or where to place the content within the file.
Resolution: Run `git status` to identify the conflicting file, open the file to edit it manually, and remove the conflict markers (`<<<<<`, `=====`, `>>>>>`). Then, run `git add` followed by `git commit` to save the changes and push them to Git.
