# Product Backlog - Mini Online Shop

| ID | Owner | User Story |
|----|-------|------------|
| US-101 | M3 | As a customer, I want to log in with my email and password, so that I can access my personal account. |
| US-102 | M4 | As a customer, I want to view a list of products, so that I can choose what to buy. |
| US-103 | M5 | As a customer, I want to add products to a shopping cart, so that I can buy several items at once. |
| US-104 | M6 | As a customer, I want to check out my cart, so that I can see the total amount to pay. |
| US-105 | M7 | As a shop admin, I want to see all orders, so that I can track sales and delivery. |
